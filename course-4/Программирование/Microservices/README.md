## Лабораторная работа #5. Django REST Framework: (микро)сервисы



## 1. Цель работы
Разработать систему микросервисов для анализа данных голосований с использованием фреймворка Django и библиотеки Django REST Framework. Реализовать функционал сбора статистики, фильтрации данных, визуализации результатов и экспорта отчетов.

## 2. Задание
1. Создать Django-проект и настроить приложение для работы с голосованиями.
2. Реализовать микросервисную архитектуру для аналитики данных.
3. Разработать следующие микросервисы:
    - **Микросервис статистики**: получение детальной информации по голосованию.
    - **Микросервис фильтрации и сортировки**: поиск и упорядочивание списка голосований.
    - **Микросервис визуализации**: генерация графиков результатов.
    - **Микросервис экспорта**: выгрузка данных в форматы CSV и JSON.
4. Реализовать веб-интерфейс для взаимодействия с микросервисами.

## 3. Ход работы

### 3.1. Структура проекта
Проект состоит из двух основных приложений:
- `polls`: отвечает за модели данных (`Poll`, `Choice`, `Vote`) и базовый функционал голосования.
- `poll_analytics`: содержит логику микросервисов для обработки и анализа данных.

### 3.2. Реализация микросервисов

#### Микросервис 1: Статистика (`StatisticsView`)
Микросервис агрегирует данные о голосах для конкретного опроса, подсчитывает общее количество голосов и процентное соотношение для каждого варианта ответа.


#### Микросервис 2: Сортировка и фильтрация (`PollsListView`)
Позволяет фильтровать голосования по датам, искать по тексту вопроса и сортировать по популярности или дате создания.

**Параметры запроса:**
- `date_from`, `date_to`: диапазон дат.
- `search`: поиск по подстроке.
- `sort_by`: поле сортировки (`date`, `popularity`).

#### Микросервис 3: Визуализация (`ChartView`)
Генерирует столбчатую диаграмму с использованием библиотеки `matplotlib`. График возвращается в формате base64 для встраивания в HTML-страницу.



#### Микросервис 4: Экспорт данных (`ExportView`)
Обеспечивает выгрузку статистики в форматы CSV и JSON. Для CSV реализовано форматирование с разделителями и визуализацией доли голосов (текстовый прогресс-бар).

**Особенности реализации CSV экспорта:**
- Использование `io.StringIO` для создания буфера.
- Добавление BOM (`\ufeff`) для корректного отображения кириллицы в Excel.
- Визуализация доли голосов символами псевдографики (`██░░`).

Получены навыки работы с библиотеками `matplotlib` для построения графиков и модулем `csv` для генерации отчетов.
